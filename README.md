# PowerBi-Data-professional-survey
This project visualizes insights from a global Data Professional Survey using Power BI.
The dashboard provides a clear breakdown of demographics, skills, salary trends, and satisfaction levels among data professionals.

📊 Visualizations Included

Treemap – Survey participant distribution by country

Bar Chart – Average salary by job title

Stacked Column Chart – Favorite programming languages by job role

Donut Chart – Difficulty of breaking into the data field

Gauge Charts – Happiness with work & happiness with salary

KPI Cards – Total respondents and average age

📈 What the Dashboard Analyzes

Geographic distribution of data professionals

Salary variations across different job titles

Most preferred programming languages

Perceived difficulty entering the data career path

Job satisfaction and salary satisfaction

Age and participation metrics

🛠 Tools Used

Power BI

Data modeling

DAX for KPIs & measures
